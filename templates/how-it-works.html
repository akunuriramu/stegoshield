Technology Primer

How StegoShield Works

Understanding Least Significant Bit (LSB) steganography and cryptographic packaging.

Fundamental Concept

1. Pixels and Color Channels

A digital image is a 2D matrix of pixels. In standard 24-bit RGB images, each pixel consists of three color channels: Red, Green, and Blue.

Each channel is represented by an 8-bit unsigned integer ranging from 0 (darkest) to 255 (brightest).

// Example Pixel (RGB)
Pixel(x=10, y=25):
Red = 255 ==> 11111111 (in binary)
Green = 120 ==> 01111000 (in binary)
Blue = 80 ==> 01010000 (in binary)
The Core Mechanism

2. Least Significant Bit (LSB) Substitution

The Least Significant Bit is the rightmost bit of an 8-bit byte. It carries a mathematical weight of exactly $2^0 = 1$. Flipping this single bit alters the channel value by at most $\pm 1$ out of 255 (a deviation of less than 0.39%).

Original Channel Byte (255)

1 1 1 1 1 1 1 1
Value: 255 (100% Brightness)

Stego Channel Byte (254)

1 1 1 1 1 1 1 0
Value: 254 (99.61% Brightness) — Imperceptible

Because the human eye cannot perceive a 0.39% variance in color intensity on an electronic display, the modified image appears 100% visually identical to the original.

Structured Protocol

4. Structured 48-Byte Binary Header

Unlike naive steganography implementations that append fragile text delimiters (such as ###END###), StegoShield embeds an exact binary header:

+-----------------------------------------------------------------------------------------+
| MAGIC (8B) | VER (1B) | FLAGS (1B) | RES (2B) | LENGTH (4B uint32) | SHA-256 CHECKSUM (32B) |
| "STGSHLD!" | 0x01 | 0x01 (Enc) | 0x0000 | Big-Endian bytes | Cryptographic Digest |
+-----------------------------------------------------------------------------------------+
  • Magic Identifier (STGSHLD!): Prevents reading random noise from normal photos. If missing, extraction halts immediately.
  • Flags: Signals whether AES-256-GCM decryption is mandatory before parsing.
  • Payload Length: Instructs the decoder exactly how many bits to read, avoiding extraneous data extraction.
  • SHA-256 Checksum: Verifies payload authenticity before decryption or presentation.
Critical Technical Requirement

5. Why PNG Format is Strictly Required

JPEG uses discrete cosine transform (DCT) lossy compression, rounding high-frequency spatial details to reduce file sizes. Because LSB modifications reside in the lowest bit of pixel frequencies, JPEG compression destroys hidden data completely.

PNG (Portable Network Graphics) uses DEFLATE lossless compression, guaranteeing that every single pixel and every individual bit remains bit-exact upon saving and downloading.
